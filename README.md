# Air Raid Alert Forecasting

Python pipeline for forecasting next-day air raid alert activity for 23 Ukrainian
oblast-capital units.

## Status

The project is currently scaffolded. Pipeline stages and implementation details will
be added task by task.

## Advisory disclaimer

This project produces advisory planning information only. It is not an alert or
warning system and must not be used as a substitute for official civil-defence alerts
or instructions from Ukrainian authorities.
